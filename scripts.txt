Download a single video:  python downloader.py "https://youtube.com/watch?v=VIDEO_ID"
Download a single video w/ age restriction: python downloader.py "https://youtu.be/wiGlOf3mCVM?si=dCFK75zR2M8SRnJY" --cookies firefox
Download audio only:  python downloader.py "https://youtube.com/watch?v=VIDEO_ID" --audio

Batch download multiple videos:  Create a text file (e.g., urls.txt) with one URL per line: python downloader.py --batch urls.txt 
Batch download multiple videos w/ age restriction: python downloader.py --batch urls.txt --cookies firefox
